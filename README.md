# Paradise Nursery 🌿

Paradise Nursery is an online plant shopping application built with React and Redux Toolkit. Browse houseplants, explore categories, add plants to a shopping cart, and manage quantities.

## Features

- Responsive landing page with a background image
- About Us page
- 18 houseplants across 3 categories
- Product images, names, and prices
- Add-to-cart buttons that disable after adding
- Dynamic cart item count
- Increase/decrease quantities and remove products
- Automatic line totals and cart total
- Continue Shopping and Checkout (Coming Soon) actions

## Technologies

- React
- JavaScript
- CSS
- Redux Toolkit and React Redux
- React Router
- Vite

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
